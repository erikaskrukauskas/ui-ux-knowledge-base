# Project-start checklist

Run this at the start of a project and again before a large interface change. The [consultation protocol](consultation-protocol.md) is the short form. This list is the one that has to be checked off.

## Checklist

- [ ] Project agent instructions include the consultation protocol and the correct path to this repo.
- [ ] The AI knowledge base path is set for questions about briefing, searching, comparing, verifying, or recording AI-assisted work.
- [ ] Application implementation, data science, data engineering, and CI/CD repos are linked from the project when the work touches them.
- [ ] Searched this repo for the interface question (`accessibility`, `empty`, `hierarchy`, `usability`, or the interaction name).
- [ ] Searched `Lessons-Learned/` for verified lessons in a similar interface situation.
- [ ] Named the user, the task, the constraint, and the usability or accessibility check that defines done.
- [ ] Confirmed any criterion or platform rule the design depends on, using the current official page.
- [ ] Stated where new lessons will go: UI/UX here, AI tooling in the AI knowledge base, implementation in the application repo, product facts in the product.

## After the work

- [ ] The named usability or accessibility check was run, and the result is in the session notes.
- [ ] A lesson was added here only when a later product would otherwise repeat the same finding.
- [ ] Secrets, research recordings of real users, copyrighted books, and verbatim manuals stayed out of every knowledge repo.
