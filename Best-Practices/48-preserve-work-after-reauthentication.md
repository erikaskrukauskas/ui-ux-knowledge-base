# Preserve work after reauthentication

When a signed-in session expires, the person can sign in again and continue without losing what they entered.

## When it applies

Use this for a form, a draft, or any activity that outlasts the session.

## The decision

- Store the in-progress work before the session ends, or restore it after sign-in.
- Return the person to the same step.
- Confirm the current criterion. It is stronger than a generic timeout warning.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "When an authenticated session expires, the user can continue the activity without loss of data after re-authenticating." Confirm the current page before you rely on it: [Preserve work after reauthentication](https://www.w3.org/TR/WCAG22/#re-authenticating).
