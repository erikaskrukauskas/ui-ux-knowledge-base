# Audio-describe prerecorded video

Prerecorded video in synchronized media has audio description of the visual information.

## When it applies

Use this when you are meeting the stronger description requirement, not only offering a separate transcript.

## The decision

- Describe what the picture shows that the dialogue does not.
- Place the description in the pauses, or use extended description when the pauses are too short.
- Confirm whether your target level requires this description or allows a full alternative instead.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Audio description is provided for all prerecorded video content in synchronized media." Confirm the current page before you rely on it: [Audio-describe prerecorded video](https://www.w3.org/TR/WCAG22/#audio-description-prerecorded).
