# Operate a carousel from the keyboard

Every carousel action, including moving between items, works from the keyboard.

## When it applies

Use this when a view shows one item from a set and offers a way to change it.

## The decision

- Provide previous, next, and a way to choose an item.
- Do not require a pointer gesture.
- Name the controls for the action, not for the chevron graphic.

## Evidence

W3C Web Accessibility Initiative, Carousels Tutorial: "All functionality, including navigating between carousel items, must be operable by keyboard." Confirm the current page before you rely on it: [Operate a carousel from the keyboard](https://www.w3.org/WAI/tutorials/carousels/).
