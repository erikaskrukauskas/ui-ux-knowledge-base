# Keep every tab in view

The tab list stays short enough that every tab is visible. Hidden tabs are easy to miss.

## When it applies

Use this when you add another tab.

## The decision

- Prefer fewer tabs.
- If the list overflows, the hidden labels are no longer a visible choice.
- Choose another structure when the set will not fit.

## Evidence

Nielsen Norman Group, last reviewed 2 September 2026: "The fewer tabs, the better." Confirm the current page before you rely on it: [Keep every tab in view](https://www.nngroup.com/articles/tabs-used-right/).
