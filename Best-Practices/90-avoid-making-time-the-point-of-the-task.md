# Avoid making time the point of the task

Timing is not essential to the activity, except for non-interactive synchronized media and real-time events. This is the stronger timing criterion.

## When it applies

Use this when you can remove a clock entirely.

## The decision

- Design the task so a slower person can finish.
- A live event or prerecorded media may still be time-based. Confirm those exceptions.
- A countdown that exists only to hurry the person fails this criterion.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Timing is not an essential part of the event or activity presented by the content, except for non-interactive synchronized media and real-time events." Confirm the current page before you rely on it: [Avoid making time the point of the task](https://www.w3.org/TR/WCAG22/#no-timing).
