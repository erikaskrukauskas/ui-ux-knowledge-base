# Size the field to the answer

A text field is about as wide as the answer, so the person can see what they entered.

## When it applies

Use this when you set the width of a field.

## The decision

- Match the width to the longest answer you reasonably expect.
- Do not clip the value they need to check.
- A field that is much larger than the answer suggests a longer entry than you want.

## Evidence

Nielsen Norman Group, 1 May 2016: "Text fields should be about the same size as the expected input since it’s extremely error prone when users can’t see their full entry." Confirm the current page before you rely on it: [Size the field to the answer](https://www.nngroup.com/articles/web-form-design/).
