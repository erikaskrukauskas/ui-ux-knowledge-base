# Match the control to the expected outcome

A control corresponds to the outcome the person expects from the physical or task convention. The arrangement matches the result, so they do not translate a private mapping.

## When it applies

Use this when several controls affect several objects, such as a set of options in a row.

## The decision

- Arrange controls to match the arrangement of the things they affect.
- Make the control's result the one its label and position suggest.
- When the platform has a convention for the action, follow it. Confirm the current platform page.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "When a design’s controls follow real-world conventions and correspond to desired outcomes (called natural mapping), it’s easier for users to learn and remember how the interface works."
