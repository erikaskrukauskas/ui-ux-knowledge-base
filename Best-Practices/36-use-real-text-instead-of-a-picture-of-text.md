# Use real text instead of a picture of text

When the platform can style real text, use real text. A picture of text is for a logo or a presentation that would lose its meaning as text.

## When it applies

Use this for headings, buttons, and quotations that someone might otherwise export as an image.

## The decision

- Set type with text the person can select, resize, and restyle.
- A logo may stay an image. Give it a text alternative.
- If an image of text can be customized to the person's requirements, the criterion allows that exception. Confirm it.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "If the technologies being used can achieve the visual presentation, text is used to convey information rather than images of text except for the following." Confirm the current page before you rely on it: [Use real text instead of a picture of text](https://www.w3.org/TR/WCAG22/#images-of-text).
