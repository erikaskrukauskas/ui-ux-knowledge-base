# Label an icon with visible text

An icon gets a visible text label. Most icons do not mean the same thing everywhere.

## When it applies

Use this for navigation and for any icon that is not a truly standard action.

## The decision

- Show the word next to the icon.
- Do not reveal the word only on hover.
- A hover label fails on a touch screen and costs an extra step.

## Evidence

Nielsen Norman Group, 27 July 2014: "To help overcome the ambiguity that almost all icons face, a text label must be present alongside an icon to clarify its meaning in that particular context." Confirm the current page before you rely on it: [Label an icon with visible text](https://www.nngroup.com/articles/icon-usability/).
