# Extend description when speech does not pause

When the dialogue never pauses long enough for a description, the video pauses so the description can finish.

## When it applies

Use this when audio description cannot fit in the natural gaps.

## The decision

- Pause the foreground audio and add the missing description.
- Resume at the same point in the video.
- Confirm the current criterion before you decide the pauses are long enough.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Where pauses in foreground audio are insufficient to allow audio descriptions to convey the sense of the video, extended audio description is provided for all prerecorded video content in synchronized media." Confirm the current page before you rely on it: [Extend description when speech does not pause](https://www.w3.org/TR/WCAG22/#extended-audio-description-prerecorded).
