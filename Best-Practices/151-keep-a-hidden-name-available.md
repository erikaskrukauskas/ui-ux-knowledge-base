# Keep a hidden name available

A label hidden from sight is still in the control's name.

## When it applies

Use this only when the visible context already identifies the field, such as a search field beside a Search button.

## The decision

- Provide the name in the control.
- Do not remove it from assistive technology.
- Prefer a visible label when there is any doubt.

## Evidence

W3C Web Accessibility Initiative, Labeling Controls: "The label can be hidden visually, though it still needs to be provided within the code to support other forms of presentation and interaction, such as for screen reader and speech input users." Confirm the current page before you rely on it: [Keep a hidden name available](https://www.w3.org/WAI/tutorials/forms/labels/).
