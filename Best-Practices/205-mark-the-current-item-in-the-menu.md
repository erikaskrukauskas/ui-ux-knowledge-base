# Mark the current item in the menu

The current item in a menu is marked in text, and it is not a control that pretends to go somewhere.

## When it applies

Use this for the item that matches the open view.

## The decision

- Say that it is the current page.
- Do not leave it as an ordinary link that reloads the same view.
- Style alone is not the marker.

## Evidence

W3C Web Accessibility Initiative, Menu Structure: "Use markup to indicate the current item of a menu, such as the current page on a website, to improve orientation in the menu." Confirm the current page before you rely on it: [Mark the current item in the menu](https://www.w3.org/WAI/tutorials/menus/structure/).
