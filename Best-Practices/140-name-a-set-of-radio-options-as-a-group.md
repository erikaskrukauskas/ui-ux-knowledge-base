# Name a set of radio options as a group

Radio options that are one choice share a group name.

## When it applies

Use this whenever the person picks one of several radios.

## The decision

- Name the question once for the group.
- Name each option for its own answer.
- Do not leave the options as a list of labels with no question.

## Evidence

W3C Web Accessibility Initiative, Grouping Controls: "Radio button groups should always be grouped using fieldset." Confirm the current page before you rely on it: [Name a set of radio options as a group](https://www.w3.org/WAI/tutorials/forms/grouping/).
