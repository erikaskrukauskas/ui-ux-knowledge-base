# Let people pause a carousel

A carousel that moves on its own has a pause control. Movement makes the text hard to read.

## When it applies

Use this when slides advance without a request.

## The decision

- Provide a control that stops and resumes the motion.
- Keep focus on that control when its label changes.
- Pausing is also appropriate when the pointer or the keyboard is on the carousel.

## Evidence

W3C Web Accessibility Initiative, Carousels Tutorial: "Users must be able to pause carousel movement because it can be too fast or distracting, making text hard to read." Confirm the current page before you rely on it: [Let people pause a carousel](https://www.w3.org/WAI/tutorials/carousels/).
