# Represent a menu as a list

A menu is a list, so the number of items and the relationships are available.

## When it applies

Use this for navigation and for a sequence of steps presented as a menu.

## The decision

- Use a list whose order matches the menu people see.
- Use an ordered list when the sequence itself matters.
- Name the menu when the view has more than one.

## Evidence

W3C Web Accessibility Initiative, Menu Structure: "Convey the menu structure, typically by using a list." Confirm the current page before you rely on it: [Represent a menu as a list](https://www.w3.org/WAI/tutorials/menus/structure/).
