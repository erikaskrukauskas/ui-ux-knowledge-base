# Show recent work so the person can resume

Show the pages, searches, or items the person used recently so they can resume without reconstructing the path from memory.

## When it applies

Use this when a task is often interrupted and continued later.

## The decision

- Show recent items in the place they return to.
- Let them recognize the item instead of remembering its name.
- A saved list serves the same purpose when the recent list would be too long.

## Evidence

Nielsen Norman Group, 15 January 2024: "Providing access to the pages recently visited and searches performed in the near past can help users resume tasks that they left incomplete and that may have difficulty recalling." Confirm the current page before you rely on it: [Show recent work so the person can resume](https://www.nngroup.com/articles/recognition-and-recall/).
