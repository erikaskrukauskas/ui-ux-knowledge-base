# Operate every function from the keyboard

Under the stronger keyboard criterion, every function works from the keyboard, with no exception for a path-based gesture, and without timing individual keystrokes.

## When it applies

Use this when that criterion is in scope. The general keyboard expectation still applies when it is not.

## The decision

- Provide a keyboard path for every function.
- Do not require a timed sequence of keystrokes.
- Confirm the current criterion before you keep a mouse-only path.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "All functionality of the content is operable through a keyboard interface without requiring specific timings for individual keystrokes." Confirm the current page before you rely on it: [Operate every function from the keyboard](https://www.w3.org/TR/WCAG22/#keyboard-no-exception).
