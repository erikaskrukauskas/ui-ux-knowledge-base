# Offer a faster path without hiding the basic one

A frequent action can have a shortcut. The visible path remains for someone who does not know the shortcut.

## When it applies

Use this for a repeated command.

## The decision

- Keep the labeled control.
- Add a shortcut for people who already know the task.
- Do not make the shortcut the only explanation.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Shortcuts — hidden from novice users — may speed up the interaction for the expert user so that the design can cater to both inexperienced and experienced users." Confirm the current page before you rely on it: [Offer a faster path without hiding the basic one](https://www.nngroup.com/articles/ten-usability-heuristics/).
