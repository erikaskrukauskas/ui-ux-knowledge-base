# Name each region of an image map

An image with several targets names the set and names each target's purpose.

## When it applies

Use this when one picture contains more than one link.

## The decision

- Give the image an alternative that says what the set of links is.
- Give each clickable area an alternative for its own destination.
- Do not leave an area named only by its coordinates.

## Evidence

W3C Web Accessibility Initiative, Images Tutorial: "The text alternative for an image that contains multiple clickable areas should provide an overall context for the set of links." Confirm the current page before you rely on it: [Name each region of an image map](https://www.w3.org/WAI/tutorials/images/).
