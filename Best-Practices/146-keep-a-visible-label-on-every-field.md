# Keep a visible label on every field

People need to see the label. A name that only assistive technology hears is for the rare field the view already names.

## When it applies

Use this for text fields, choices, and lists.

## The decision

- Show the label.
- Hide it only when the surrounding control already says the same thing, and still expose the name.
- Do not remove labels to save space.

## Evidence

W3C Web Accessibility Initiative, Labeling Controls: "However, most users prefer or even need visible labels to understand the form." Confirm the current page before you rely on it: [Keep a visible label on every field](https://www.w3.org/WAI/tutorials/forms/labels/).
