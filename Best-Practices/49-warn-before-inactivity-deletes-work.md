# Warn before inactivity deletes work

If inactivity will destroy the person's data, tell them the duration ahead of time, unless the data is kept for more than 20 hours.

## When it applies

Use this when a timeout clears a draft or a cart. Privacy rules may limit storing data before the person is known. Confirm that note.

## The decision

- State how long inactivity can last before data is lost.
- Say it before the timer is the only warning.
- Confirm the current 20-hour preservation figure before you rely on it.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Users are warned of the duration of any user inactivity that could cause data loss, unless the data is preserved for more than 20 hours when the user does not take any actions."
