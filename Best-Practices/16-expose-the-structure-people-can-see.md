# Expose the structure people can see

Relationships that the layout shows are also available as structure, or in text. A heading, a group, a required field, or a table header that is only a visual style disappears when the presentation changes.

## When it applies

Use this when presentation implies a relationship: a larger heading, a grouped set of fields, a list, a required marker, or a cell that only makes sense with its row and column.

## The decision

- Mark headings, lists, groups, and table headers as that structure, in an order that matches the task.
- If the platform cannot expose the relationship, state it in text next to the content. "Required" is text, not only a color.
- Keep the visible label and the exposed name in agreement. See [Name the outcome on the control](11-name-the-outcome-on-the-control.md).
- Do not use a heading style, indentation, or color as the only carrier of the relationship.

## Evidence

W3C, Understanding Success Criterion 1.3.1 Info and Relationships: "Use code to reinforce relationships and information conveyed through presentation." The criterion says information, structure, and relationships conveyed through presentation can be programmatically determined or are available in text. Confirm the current page before you rely on it: [Info and Relationships](https://www.w3.org/WAI/WCAG22/Understanding/info-and-relationships.html).
