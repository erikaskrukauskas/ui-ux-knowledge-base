# Show one parent path

When a view has more than one parent, the breadcrumb shows one canonical path.

## When it applies

Use this in a structure where a page can live in several places.

## The decision

- Pick one path and show that trail.
- Do not show every possible trail. They compete and take the top of the view.
- Do not rewrite the trail to match each person's private route.

## Evidence

Nielsen Norman Group, last reviewed 1 September 2026: "If a page has multiple different parents, identify a canonical path to it in the site hierarchy and show that path in the breadcrumb trail." Confirm the current page before you rely on it: [Show one parent path](https://www.nngroup.com/articles/breadcrumbs/).
