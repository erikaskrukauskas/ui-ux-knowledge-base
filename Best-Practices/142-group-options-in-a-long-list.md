# Group options in a long list

A long list of options is grouped, and each group is named.

## When it applies

Use this when a single list mixes several categories.

## The decision

- Name each category.
- Keep options that belong together inside that category.
- Do not offer one flat list when the categories are how the person searches.

## Evidence

W3C Web Accessibility Initiative, Grouping Controls: "For select elements with groups of options, the optgroup element can be used to indicate such groups." Confirm the current page before you rely on it: [Group options in a long list](https://www.w3.org/WAI/tutorials/forms/grouping/).
