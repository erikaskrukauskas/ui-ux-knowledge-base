# Use headings to organize long text

Long text is organized with headings that introduce the sections. This criterion is about the writing, not about naming a button.

## When it applies

Use this for an article, a policy, or help text with more than one topic.

## The decision

- Add a heading where the topic changes.
- Make the heading say the topic of what follows.
- Expose those headings as structure, not only as bold text.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Section headings are used to organize the content." Confirm the current page before you rely on it: [Use headings to organize long text](https://www.w3.org/TR/WCAG22/#section-headings).
