# Keep images that carry the interface

Do not strip the interface down to a text-only copy. Name the images instead.

## When it applies

Use this when someone proposes a separate text-only version of a view.

## The decision

- Keep the images that help people understand the view.
- Provide a text alternative for each one that carries information or an action.
- A second, thinner version is not a substitute for that alternative.

## Evidence

W3C Web Accessibility Initiative, Images Tutorial: "Removing images from websites (so-called “text-only versions”) make them less accessible and functional for these users and situations." Confirm the current page before you rely on it: [Keep images that carry the interface](https://www.w3.org/WAI/tutorials/images/).
