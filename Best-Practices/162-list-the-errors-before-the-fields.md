# List the errors before the fields

When several fields fail, list the errors before the form, each linked to its field.

## When it applies

Use this after a submission with more than one error.

## The decision

- Give the list a heading.
- Name the field, say what is wrong, and say how to fix it.
- Link each item to its control.

## Evidence

W3C Web Accessibility Initiative, User Notification: "When errors occur, it is helpful to list them at the top of the page, before the form." Confirm the current page before you rely on it: [List the errors before the fields](https://www.w3.org/WAI/tutorials/forms/notifications/).
