# Make an error unmistakable

An input error uses several cues at once. This is not the moment to be subtle.

## When it applies

Use this when a field fails validation.

## The decision

- Mark the field and write the message in text.
- Use more than one visual cue, such as a border and weight, along with the words.
- Keep the person's entry so they can correct it.

## Evidence

Nielsen Norman Group, 1 May 2016: "Errors should be signaled through a variety of cues, not solely through color." Confirm the current page before you rely on it: [Make an error unmistakable](https://www.nngroup.com/articles/web-form-design/).
