# Keep the group name short

A group name that is read with every control stays short.

## When it applies

Use this when related fields or options share one legend.

## The decision

- Put shared facts, such as required, in that short name when they apply to the whole group.
- Put field-specific format help on the field.
- Cut words that will be repeated on every control.

## Evidence

W3C Web Accessibility Initiative, Grouping Controls: "Make the legend as short as possible for situations in which it is read together with the label each time." Confirm the current page before you rely on it: [Keep the group name short](https://www.w3.org/WAI/tutorials/forms/grouping/).
