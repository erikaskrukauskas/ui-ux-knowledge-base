# Do not invent an icon for an abstract idea

If you cannot think of an icon quickly, an icon will not carry that meaning. Use words.

## When it applies

Use this when a navigation item or an action has no familiar symbol.

## The decision

- Use a text label.
- Test a new icon with people before you rely on it.
- A symbol that takes effort to invent will take effort to learn.

## Evidence

Nielsen Norman Group, 27 July 2014: "Use the 5-second rule: if it takes you more than 5 seconds to think of an appropriate icon for something, it is unlikely that an icon can effectively communicate that meaning." Confirm the current page before you rely on it: [Do not invent an icon for an abstract idea](https://www.nngroup.com/articles/icon-usability/).
