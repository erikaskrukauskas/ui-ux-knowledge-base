# Give meaningful images a text alternative

An image, icon, or chart that carries meaning has a text alternative that serves the same purpose. Decoration is marked so assistive technology can skip it.

## When it applies

Use this when a non-text element is shown to the person.

## The decision

- Write the alternative as the purpose, not as a file name.
- A control's alternative is its accessible name. See the labels rule.
- If the image is only decoration, hide it from assistive technology instead of adding a noisy description.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "All non-text content that is presented to the user has a text alternative that serves the equivalent purpose, except for the situations listed below." Confirm the current page before you rely on it: [Give meaningful images a text alternative](https://www.w3.org/TR/WCAG22/#non-text-content).
