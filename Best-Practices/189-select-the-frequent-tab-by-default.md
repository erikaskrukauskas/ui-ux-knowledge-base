# Select the frequent tab by default

The tab people need most is first and already selected.

## When it applies

Use this when you choose the default tab.

## The decision

- Order the list by frequency.
- Select the frequent tab by default.
- Leave a rare tab available, not selected.

## Evidence

Nielsen Norman Group, last reviewed 2 September 2026: "Arrange tab content so high-use content is first in the list and selected by default." Confirm the current page before you rely on it: [Select the frequent tab by default](https://www.nngroup.com/articles/tabs-used-right/).
