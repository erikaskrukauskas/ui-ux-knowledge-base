# Suggest the fix instead of only naming the fault

When the system can tell what a valid next value is, offer that fix. Naming the fault without a remedy leaves the person to guess.

## When it applies

Use this for a mismatch the system can resolve, such as a city that does not match a code.

## The decision

- Offer the likely correction.
- Let them accept it in one action when there is a single likely value.
- Skip the suggestion when it would reveal a secret.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Offer users a solution, like a shortcut that can solve the error immediately." Confirm the current page before you rely on it: [Suggest the fix instead of only naming the fault](https://www.nngroup.com/articles/ten-usability-heuristics/).
