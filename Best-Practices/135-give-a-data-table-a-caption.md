# Give a data table a caption

A data table has a caption that says what the grid is about.

## When it applies

Use this when a grid of related values is shown.

## The decision

- Write a short caption, as you would a heading.
- Put it with the table so it is announced with the table.
- Do not make the person infer the topic only from the first row.

## Evidence

W3C Web Accessibility Initiative, Caption and Summary: "A caption functions like a heading for a table." Confirm the current page before you rely on it: [Give a data table a caption](https://www.w3.org/WAI/tutorials/tables/caption-summary/).
