# Summarize a complex table without repeating the caption

A complex table can add a summary of how it is organized. That summary does not restate the caption.

## When it applies

Use this when row and column structure is unusual enough that a person needs a map.

## The decision

- Say which column or row holds which kind of fact.
- Keep the caption as the topic.
- Leave the summary out when the caption and the headers are already enough.

## Evidence

W3C Web Accessibility Initiative, Caption and Summary: "If both caption and summary are provided for one table, the summary should not duplicate information present in the caption." Confirm the current page before you rely on it: [Summarize a complex table without repeating the caption](https://www.w3.org/WAI/tutorials/tables/caption-summary/).
