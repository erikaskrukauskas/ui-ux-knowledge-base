# Match the warning to the severity

A blocker asks for a decision. A notice that does not stop the task stays out of the way. Reserve an interruption for a problem the person must handle before continuing.

## When it applies

Use this when you choose between an inline message and a dialog.

## The decision

- Use an inline message for a problem they can fix in place.
- Use an interruption only when they must stop, such as unsaved work about to be discarded.
- Do not style a minor notice like a failure.

## Evidence

Nielsen Norman Group, 14 May 2023: "Design your error messages to indicate the problem's severity." Confirm the current page before you rely on it: [Match the warning to the severity](https://www.nngroup.com/articles/error-message-guidelines/).
