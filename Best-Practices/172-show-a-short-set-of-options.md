# Show a short set of options

Two or three options are shown, not hidden in a dropdown.

## When it applies

Use this when the person is choosing among a very small set.

## The decision

- Show radios or an equivalent visible choice.
- Reserve a closed list for a set too long to scan at once.
- One visible choice should take one action, not an open and then a select.

## Evidence

Nielsen Norman Group, 1 May 2016: "Avoid drop-downs when there are only 2 or 3 options that could be displayed as radio buttons (which require only a single click or tap)." Confirm the current page before you rely on it: [Show a short set of options](https://www.nngroup.com/articles/web-form-design/).
