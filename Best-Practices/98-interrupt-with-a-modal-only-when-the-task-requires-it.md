# Interrupt with a modal only when the task requires it

A modal stops the task. Use it for a critical warning, for information without which the current process cannot continue, or for a short step that belongs to that process. Do not use it for an unrelated offer.

## When it applies

Use this when something might cover the view and demand an answer.

## The decision

- Interrupt for irreversible harm or for a fact the current step cannot proceed without.
- Keep a complex decision on the page, where the supporting information is visible.
- An unrelated signup or upsell does not justify the interruption.

## Evidence

Nielsen Norman Group, 23 April 2017: "Modal dialogs interrupt users and demand an action. They are appropriate when user’s attention needs to be directed toward important information." Confirm the current page before you rely on it: [Interrupt with a modal only when the task requires it](https://www.nngroup.com/articles/modal-nonmodal-dialog/).
