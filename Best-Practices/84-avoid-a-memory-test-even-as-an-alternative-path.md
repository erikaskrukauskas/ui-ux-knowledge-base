# Avoid a memory test even as an alternative path

Under the stronger authentication criterion, a cognitive test is not required unless another method exists or the person is assisted. Object recognition and personal-content puzzles are not the fallback.

## When it applies

Use this when that stronger criterion is in scope.

## The decision

- Provide a method that does not rely on remembering or solving a puzzle, or assist the person through it.
- Do not treat a photo puzzle as the accessible path under this stronger criterion.
- Confirm the current text. It is stricter than the minimum authentication criterion.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "A cognitive function test (such as remembering a password or solving a puzzle) is not required for any step in an authentication process unless that step provides at least one of the following." Confirm the current page before you rely on it: [Avoid a memory test even as an alternative path](https://www.w3.org/TR/WCAG22/#accessible-authentication-enhanced).
