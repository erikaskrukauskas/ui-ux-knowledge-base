# Hide a decorative image from the name

A decorative image adds no information, so assistive technology skips it.

## When it applies

Use this when a picture is a border, a spacer, or an illustration of text already beside it.

## The decision

- Decide whether the image adds information the adjacent text does not.
- If it does not, give it an empty alternative so the file name is not announced.
- If the picture marks a real break in the topic, expose that break as structure instead.

## Evidence

W3C Web Accessibility Initiative, Decorative Images: "Decorative images don’t add information to the content of a page." Confirm the current page before you rely on it: [Hide a decorative image from the name](https://www.w3.org/WAI/tutorials/images/decorative/).
