# Put repeated help in the same order

When help is repeated across views, human contact, self-help, and automated contact stay in the same relative order.

## When it applies

Use this when more than one view offers help.

## The decision

- Keep the help mechanisms in the same order relative to the rest of the content.
- A direct link to a help view counts. It still occupies the same relative place.
- The person may change zoom or orientation. Compare views that use the same variation.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "If a web page contains any of the following help mechanisms, and those mechanisms are repeated on multiple web pages within a set of web pages, they occur in the same order relative to other page content, unless a change is initiated by the user." Confirm the current page before you rely on it: [Put repeated help in the same order](https://www.w3.org/TR/WCAG22/#consistent-help).
