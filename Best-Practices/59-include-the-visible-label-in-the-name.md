# Include the visible label in the name

If a control shows text, its accessible name contains that text. Put the visible words at the start of the name.

## When it applies

Use this when speech control or a screen reader will activate the control by its visible words.

## The decision

- The accessible name includes the visible label.
- Start the name with those visible words.
- A name that adds unseen words and drops the visible ones fails the criterion.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "For user interface components with labels that include text or images of text, the name contains the text that is presented visually." Confirm the current page before you rely on it: [Include the visible label in the name](https://www.w3.org/TR/WCAG22/#label-in-name).
