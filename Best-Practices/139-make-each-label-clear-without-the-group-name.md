# Make each label clear without the group name

A field's own label still makes sense if the group name is not read with it.

## When it applies

Use this when several fields share a group label, such as two addresses.

## The decision

- Keep the group name short, because it may be read with every field.
- Write each field label so it can stand alone.
- Do not copy the whole group name into every field.

## Evidence

W3C Web Accessibility Initiative, Grouping Controls: "Make the individual labels sufficiently self-explanatory for situations in which legends are not read aloud, without repeating the legend in every label." Confirm the current page before you rely on it: [Make each label clear without the group name](https://www.w3.org/WAI/tutorials/forms/grouping/).
