# Label every menu on the view

Each menu has a short name so it can be found and distinguished.

## When it applies

Use this when a view has one or more menus.

## The decision

- Name it for its purpose.
- Use a heading or another visible label when the person needs to see it.
- Two unlabeled menus of the same type cannot be told apart.

## Evidence

W3C Web Accessibility Initiative, Menu Structure: "Label menus to make them easier to find and understand." Confirm the current page before you rely on it: [Label every menu on the view](https://www.w3.org/WAI/tutorials/menus/structure/).
