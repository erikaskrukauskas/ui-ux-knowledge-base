# Name the step in the main heading

The main heading shows the same progress a person sees when they scan.

## When it applies

Use this on every step of a multi-step form.

## The decision

- Include the step name and the count.
- Keep it the most prominent heading.
- Match the heading and the view title.

## Evidence

W3C Web Accessibility Initiative, Multi-page Forms: "Using the main heading to inform users is a good way to provide the same information for people scanning the page visually." Confirm the current page before you rely on it: [Name the step in the main heading](https://www.w3.org/WAI/tutorials/forms/multi-page/).
