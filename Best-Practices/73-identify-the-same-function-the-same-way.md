# Identify the same function the same way

A control that does the same thing across views uses the same name and identification.

## When it applies

Use this for search, save, next, and any repeated action.

## The decision

- Pick one name for one function and keep it.
- An icon that means the same action stays with the same name.
- A different function gets a different name, even if the shape is similar.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Components that have the same functionality within a set of web pages are identified consistently." Confirm the current page before you rely on it: [Identify the same function the same way](https://www.w3.org/TR/WCAG22/#consistent-identification).
