# Offer an alternative for live audio only

Live audio with no video has an alternative that presents the same information.

## When it applies

Use this for a live audio broadcast, a voice-only event, or a live announcement.

## The decision

- Provide a text alternative that keeps up with the live audio.
- Identify it as the alternative for that audio.
- Confirm the current criterion for how complete a live alternative must be.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "An alternative for time-based media that presents equivalent information for live audio-only content is provided." Confirm the current page before you rely on it: [Offer an alternative for live audio only](https://www.w3.org/TR/WCAG22/#audio-only-live).
