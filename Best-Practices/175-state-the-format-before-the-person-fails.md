# State the format before the person fails

A format rule is visible before the person types, not only after they fail.

## When it applies

Use this for passwords, phone numbers, and any field with a syntax.

## The decision

- State the exact rule up front.
- Accept input without arbitrary punctuation when you can.
- Do not reveal the rule for the first time in an error.

## Evidence

Nielsen Norman Group, 1 May 2016: "If a field requires a specific format or type of input, state the exact instructions." Confirm the current page before you rely on it: [State the format before the person fails](https://www.nngroup.com/articles/web-form-design/).
