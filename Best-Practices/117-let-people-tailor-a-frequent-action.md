# Let people tailor a frequent action

A person who repeats an action can tailor it. The default path stays intact for everyone else.

## When it applies

Use this for a frequent view, filter, or command.

## The decision

- Let them keep a frequent choice.
- Do not require every person to set it up before the basic task works.
- The tailored path is a shortcut, not a second product.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Allow users to tailor frequent actions." Confirm the current page before you rely on it: [Let people tailor a frequent action](https://www.nngroup.com/articles/ten-usability-heuristics/).
