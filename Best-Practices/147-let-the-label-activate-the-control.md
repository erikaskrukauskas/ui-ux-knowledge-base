# Let the label activate the control

The label and the control are one target. Activating the label activates the control.

## When it applies

Use this for radios, checkboxes, and any small control.

## The decision

- Associate the visible label with that control.
- Make the label's area clickable or tappable.
- Do not leave a tiny control with a label that does nothing.

## Evidence

W3C Web Accessibility Initiative, Labeling Controls: "Web browsers provide the label as a larger clickable area, for example, to select or activate the control." Confirm the current page before you rely on it: [Let the label activate the control](https://www.w3.org/WAI/tutorials/forms/labels/).
