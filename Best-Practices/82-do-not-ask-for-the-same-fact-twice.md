# Do not ask for the same fact twice

Information the person already provided in this process is filled in or offered for them to select, unless re-entry is essential, needed for security, or the old value is no longer valid.

## When it applies

Use this across steps of one process.

## The decision

- Carry forward a name, address, or choice they already gave.
- Let them pick it rather than retype it.
- A password confirmation or an expired code can be the exception. Confirm it.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Information previously entered by or provided to the user that is required to be entered again in the same process is either auto-populated, or available for the user to select." Confirm the current page before you rely on it: [Do not ask for the same fact twice](https://www.w3.org/TR/WCAG22/#redundant-entry).
