# Do not use color as the only cue

Color may reinforce a meaning. It cannot be the only way that meaning is shown.

## When it applies

Use this when color marks a required field, an error, a status, a series, or a link.

## The decision

- Add text, an icon, a pattern, or a label that carries the same meaning.
- A lightness difference can help tell two colors apart. It does not replace a cue when the person must know which hue means which state.
- Confirm the current criterion before you treat a contrast note as the exception.

## Evidence

W3C, Understanding Success Criterion 1.4.1 Use of Color: "Color is not used as the only visual means of conveying information, indicating an action, prompting a response, or distinguishing a visual element." Confirm the current page before you rely on it: [Do not use color as the only cue](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html).
