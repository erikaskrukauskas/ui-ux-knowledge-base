# Identify the purpose of common fields

Fields that collect a common fact about the person, such as a name or an address, expose that purpose so a browser or assistive tool can fill them.

## When it applies

Use this when the platform can express the purpose of a user field.

## The decision

- Mark the purpose of fields that ask for the person's own information.
- Keep the visible label in the person's language. The purpose token is for the tool.
- Confirm the current list of purposes before you invent a token.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "The purpose of each input field collecting information about the user can be programmatically determined when the input field serves a purpose identified in the Input Purposes for user interface components section." Confirm the current page before you rely on it: [Identify the purpose of common fields](https://www.w3.org/TR/WCAG22/#identify-input-purpose).
