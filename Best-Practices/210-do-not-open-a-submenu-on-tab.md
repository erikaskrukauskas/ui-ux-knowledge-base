# Do not open a submenu on tab

Tab moves across the top level. It does not force every submenu open.

## When it applies

Use this for a menu with submenus.

## The decision

- Leave submenus closed while tabbing along the top level.
- Open a submenu when the person activates it, or give it its own control.
- A keyboard user should not have to walk every child to reach the next top-level item.

## Evidence

W3C Web Accessibility Initiative, Fly-out Menus: "Submenus should not open when using the tab key to navigate through the menu, as keyboard users would then have to step through all submenu items to get to the next top-level item." Confirm the current page before you rely on it: [Do not open a submenu on tab](https://www.w3.org/WAI/tutorials/menus/flyout/).
