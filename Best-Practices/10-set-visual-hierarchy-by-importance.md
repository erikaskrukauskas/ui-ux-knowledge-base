# Set visual hierarchy by importance

Give the view one order of importance, and make that order visible. People should see the primary task first, then what supports it, then what can wait.

## When it applies

Use this when a view has more than one element and the person has to know where to start.

## The decision

- Name the one thing the person should notice first for this task. Give it the strongest scale, weight, or space.
- Group related items together, and separate groups that are not the same decision.
- Use contrast to reinforce that order. Color may help. Color is not the only cue. See [Meet accessibility expectations](05-meet-accessibility-expectations.md).
- Limit how many elements share the strongest emphasis. When everything is emphasized, nothing is first.
- Check the order by stepping back from the words. If the strongest shape is not the primary task, change the hierarchy.

## Evidence

Nielsen Norman Group: "A clear visual hierarchy guides the eye to the most important elements on the page. It can be created through variations in color and contrast, scale, and grouping." Confirm the current article before you rely on it: [Visual Hierarchy in UX: Definition](https://www.nngroup.com/articles/visual-hierarchy-ux-definition/).
