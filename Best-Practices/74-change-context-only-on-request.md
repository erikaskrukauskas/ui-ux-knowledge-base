# Change context only on request

A change of context happens because the person asked, or they can turn automatic changes off.

## When it applies

Use this when you are meeting the stronger predictable-behavior criterion.

## The decision

- Navigate, submit, or open a new context from an explicit action.
- If something must change automatically, give a way to turn that behavior off.
- Confirm the current criterion before you auto-advance a step.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Changes of context are initiated only by user request or a mechanism is available to turn off such changes." Confirm the current page before you rely on it: [Change context only on request](https://www.w3.org/TR/WCAG22/#change-on-request).
