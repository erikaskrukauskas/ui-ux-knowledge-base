# Set the language of the view

The default human language of the view is exposed so assistive technology can pronounce it.

## When it applies

Use this on every view.

## The decision

- Set the language to the language of the content.
- Change it when the view's language changes.
- A label in another language inside the view is the next rule.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "The default human language of each web page can be programmatically determined." Confirm the current page before you rely on it: [Set the language of the view](https://www.w3.org/TR/WCAG22/#language-of-page).
