# Let people reopen a completed step

A completed step can be opened again, and the current answers are kept.

## When it applies

Use this when a step indicator lists earlier steps.

## The decision

- Link the completed steps.
- Save the current step before moving.
- Return the person to the same answers they already entered.

## Evidence

W3C Web Accessibility Initiative, Multi-page Forms: "If possible, provide a link to steps already completed, so the user can review them. In this case, any data already entered in the current step should be saved." Confirm the current page before you rely on it: [Let people reopen a completed step](https://www.w3.org/WAI/tutorials/forms/multi-page/).
