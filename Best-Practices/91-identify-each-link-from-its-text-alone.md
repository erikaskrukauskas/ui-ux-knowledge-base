# Identify each link from its text alone

The person can learn each link's purpose from the link text alone, except where the purpose would be ambiguous to everyone.

## When it applies

Use this when you are meeting the stronger link criterion. The minimum criterion allows programmatic context.

## The decision

- Write link text that stands alone.
- Repeated "Read more" links fail this criterion even if each sits under a heading.
- Confirm the ambiguous-to-users exception before you keep a short link.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "A mechanism is available to allow the purpose of each link to be identified from link text alone, except where the purpose of the link would be ambiguous to users in general." Confirm the current page before you rely on it: [Identify each link from its text alone](https://www.w3.org/TR/WCAG22/#link-purpose-link-only).
