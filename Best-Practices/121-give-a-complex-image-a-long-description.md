# Give a complex image a long description

A chart, diagram, or map needs a short name and a full text equivalent of what it shows.

## When it applies

Use this when the picture holds more than one sentence of information.

## The decision

- Identify the image in a short alternative.
- Put the values, relationships, and trends in text that everyone can read.
- Point to that description from the image, and summarize the point in the surrounding text.

## Evidence

W3C Web Accessibility Initiative, Complex Images: "In these cases, a two-part text alternative is required." Confirm the current page before you rely on it: [Give a complex image a long description](https://www.w3.org/WAI/tutorials/images/complex/).
