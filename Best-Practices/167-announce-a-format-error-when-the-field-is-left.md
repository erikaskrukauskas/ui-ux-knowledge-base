# Announce a format error when the field is left

A format error found as the person leaves the field is announced before the next field.

## When it applies

Use this when the check runs on leaving the field.

## The decision

- Put the message on the field.
- Announce it so it is heard before the next control.
- Say the format they should use.

## Evidence

W3C Web Accessibility Initiative, User Notification: "The value “assertive” emphasizes the importance of the message and causes screen readers to interrupt their current tasks to read aloud this message." Confirm the current page before you rely on it: [Announce a format error when the field is left](https://www.w3.org/WAI/tutorials/forms/notifications/).
