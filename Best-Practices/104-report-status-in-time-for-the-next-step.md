# Report status in time for the next step

After an action with a consequence, tell the person what the system did, soon enough that they can choose the next step.

## When it applies

Use this for save, send, submit, and any action whose result is not obvious on the same control.

## The decision

- Say what happened.
- Say it immediately when the result is known, and show progress when it is not.
- Pair the message with the empty, loading, error, or success state for that action.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "The design should always keep users informed about what is going on, through appropriate feedback within a reasonable amount of time."
