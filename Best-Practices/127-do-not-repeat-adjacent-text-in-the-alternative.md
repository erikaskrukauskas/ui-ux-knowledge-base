# Do not repeat adjacent text in the alternative

If the words next to an image already say what it shows, the image stays silent.

## When it applies

Use this when a caption or a paragraph fully describes the picture.

## The decision

- Read the adjacent text before writing an alternative.
- Leave the alternative empty when it would only repeat that text.
- Write an alternative when the picture adds a fact the text does not.

## Evidence

W3C Web Accessibility Initiative, Decorative Images: "There is no need to repeat this information, and a null (empty) alt value can be used for this image." Confirm the current page before you rely on it: [Do not repeat adjacent text in the alternative](https://www.w3.org/WAI/tutorials/images/decorative/).
