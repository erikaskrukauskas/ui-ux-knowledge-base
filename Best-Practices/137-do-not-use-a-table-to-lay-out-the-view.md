# Do not use a table to lay out the view

A table is for related data. Layout belongs to the layout, not to a grid of cells.

## When it applies

Use this when you are tempted to place headings, images, or fields into table cells for alignment.

## The decision

- Use the layout method for placement.
- Reserve table headers and data cells for values that have a relationship.
- If a relationship is real, mark the headers. If it is only visual, do not use a table.

## Evidence

W3C Web Accessibility Initiative, Tables Tutorial: "As a general rule, tables aren’t meant to be used for layout purposes." Confirm the current page before you rely on it: [Do not use a table to lay out the view](https://www.w3.org/WAI/tutorials/tables/).
