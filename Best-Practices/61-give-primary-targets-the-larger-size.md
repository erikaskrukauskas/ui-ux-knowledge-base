# Give primary targets the larger size

When you can, size pointer targets to at least 44 by 44 CSS pixels. The minimum spacing rule is smaller. This stronger size is for targets where activation must be easy.

## When it applies

Use this for primary actions. Inline text links, untouched user-agent controls, an equivalent larger control, and essential dense layouts have the exceptions in the criterion.

## The decision

- Size important targets to at least 44 by 44 CSS pixels.
- Confirm that number. The minimum criterion is a different, smaller rule.
- Do not shrink the primary action to fit more controls in a row.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "The size of the target for pointer inputs is at least 44 by 44 CSS pixels except when." Confirm the current page before you rely on it: [Give primary targets the larger size](https://www.w3.org/TR/WCAG22/#target-size-enhanced).
