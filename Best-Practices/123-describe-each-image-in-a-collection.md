# Describe each image in a collection

A collection of related pictures names the group and names each picture.

## When it applies

Use this when each image is its own information, not a fragment of one fact.

## The decision

- Caption the collection.
- Give each image its own alternative.
- Say how that image sits in the group when the relationship matters.

## Evidence

W3C Web Accessibility Initiative, Groups of Images: "In this case, each image needs its text alternative that describes it individually, as well as its relationship within the group." Confirm the current page before you rely on it: [Describe each image in a collection](https://www.w3.org/WAI/tutorials/images/groups/).
