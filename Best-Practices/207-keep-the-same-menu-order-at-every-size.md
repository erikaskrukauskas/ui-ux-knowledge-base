# Keep the same menu order at every size

Items that remain visible keep the same order, words, and destination on every screen size.

## When it applies

Use this when a menu collapses on a small view.

## The decision

- You may hide some items in a submenu.
- Do not reorder or rename the items that still show.
- The destination of a shown item stays the same.

## Evidence

W3C Web Accessibility Initiative, Menu Structure: "Some menu items may be collapsed or even hidden in sub navigation menus, but items that show should appear in the same order and with the same wording and destination." Confirm the current page before you rely on it: [Keep the same menu order at every size](https://www.w3.org/WAI/tutorials/menus/structure/).
