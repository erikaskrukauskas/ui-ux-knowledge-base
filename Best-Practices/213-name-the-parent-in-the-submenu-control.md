# Name the parent in the submenu control

The control that opens a submenu says which parent it belongs to.

## When it applies

Use this when a button shows or hides children.

## The decision

- Include the parent name, such as show the submenu for that section.
- Change the name when the submenu is open.
- A bare show or hide is weaker when several submenus are on the view.

## Evidence

W3C Web Accessibility Initiative, Fly-out Menus: "If possible, include the name of the parent menu item in the button’s label." Confirm the current page before you rely on it: [Name the parent in the submenu control](https://www.w3.org/WAI/tutorials/menus/flyout/).
