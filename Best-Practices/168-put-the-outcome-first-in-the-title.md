# Put the outcome first in the title

Success or the error count leads the view title, so it is heard as soon as the view loads.

## When it applies

Use this when a submission reloads the view or replaces it.

## The decision

- Start with the result, such as the number of errors or the thanks.
- Then name the step.
- Match the main heading.

## Evidence

W3C Web Accessibility Initiative, User Notification: "The title element of the web page can be useful to indicate successes and errors." Confirm the current page before you rely on it: [Put the outcome first in the title](https://www.w3.org/WAI/tutorials/forms/notifications/).
