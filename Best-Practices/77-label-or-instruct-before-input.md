# Label or instruct before input

A field that requires input has a label or an instruction.

## When it applies

Use this for every field, including one that looks obvious to the team.

## The decision

- Label the field with what belongs in it.
- Add an instruction when the format is not obvious, and keep the instruction available.
- A placeholder that disappears is not the label.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Labels or instructions are provided when content requires user input." Confirm the current page before you rely on it: [Label or instruct before input](https://www.w3.org/TR/WCAG22/#labels-or-instructions).
