# Put the expected format in the label

A format the person must match is part of the label, so it stays visible while they type.

## When it applies

Use this for a date, a code, or any field with a required pattern.

## The decision

- Write the pattern in the label, such as MM/YYYY.
- Keep an example where it can still be seen after typing starts.
- Do not leave the pattern only inside the empty field.

## Evidence

W3C Web Accessibility Initiative, Form Instructions: "For simple use cases, providing instructions within labels may be sufficient." Confirm the current page before you rely on it: [Put the expected format in the label](https://www.w3.org/WAI/tutorials/forms/instructions/).
