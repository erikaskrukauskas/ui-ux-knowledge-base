# Prevent slips with a constraint or a safe default

Stop the invalid choice, or select the safe, frequent, reversible option. Do not preselect a destructive, payment, or consent choice.

## When it applies

Use this before you add another confirmation.

## The decision

- Constrain the input so an impossible value cannot be chosen.
- Default to the option most people need when it is safe and reversible.
- Leave a destructive or consent choice unselected.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Avoid slips by providing helpful constraints and good defaults." Confirm the current page before you rely on it: [Prevent slips with a constraint or a safe default](https://www.nngroup.com/articles/ten-usability-heuristics/).
