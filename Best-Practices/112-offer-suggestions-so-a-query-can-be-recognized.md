# Offer suggestions so a query can be recognized

When the person must supply a query, suggest likely queries so they can recognize one instead of recalling the exact words.

## When it applies

Use this for search and for any field whose valid values are a set the system knows.

## The decision

- Show suggestions as they type or when the field is focused.
- Let them choose a suggestion.
- Keep a way to submit their own words when none of the suggestions fit.

## Evidence

Nielsen Norman Group, 15 January 2024: "Search suggestions are a major advance in search usability because they partly transform the query-generation task from one of recall to one of recognition." Confirm the current page before you rely on it: [Offer suggestions so a query can be recognized](https://www.nngroup.com/articles/recognition-and-recall/).
