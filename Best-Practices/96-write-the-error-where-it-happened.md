# Write the error where it happened

An error is visible at the item that failed, written in plain language, with a way forward, and the person's entry still in place.

## When it applies

Use this when the system rejects or cannot complete an input.

## The decision

- Put the message next to the source.
- Say what happened and what to do. Do not blame the person or show only a code.
- Keep what they typed. Do not flag an empty field they have only tabbed through.

## Evidence

Nielsen Norman Group, 14 May 2023: "Design effective error messages by ensuring they are highly visible, provide constructive communication, and respect user effort." Confirm the current page before you rely on it: [Write the error where it happened](https://www.nngroup.com/articles/error-message-guidelines/).
