# Make help searchable and about the task

Help is easier to search, focused on the task, and written as steps. The interface still tries to be clear without it.

## When it applies

Use this when the task needs an explanation that will not fit on the control.

## The decision

- Make the help searchable.
- Put it in context when the person needs it.
- List the concrete steps. Do not substitute a tour for those steps.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Help and documentation content should be easy to search and focused on the user's task. Keep it concise, and list concrete steps that need to be carried out." Confirm the current page before you rely on it: [Make help searchable and about the task](https://www.nngroup.com/articles/ten-usability-heuristics/).
