# Make link purpose clear in context

The purpose of a link is clear from its text, or from its text plus the programmatic context around it.

## When it applies

Use this together with the rule that a control names its outcome. Context may help. It does not rescue a link whose text is only "click here" when the context is also vague.

## The decision

- Write link text that says where it goes or what it does.
- If the purpose depends on a nearby heading or sentence, that context is exposed programmatically.
- Confirm the current rule for what counts as link context.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "The purpose of each link can be determined from the link text alone or from the link text together with its programmatically determined link context, except where the purpose of the link would be ambiguous to users in general." Confirm the current page before you rely on it: [Make link purpose clear in context](https://www.w3.org/TR/WCAG22/#link-purpose-in-context).
