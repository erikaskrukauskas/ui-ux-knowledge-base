# Label regions that share a type

Two regions of the same type each get a short name so they can be told apart.

## When it applies

Use this when a view has two navigation blocks, or any repeated region type.

## The decision

- Name them for their purpose, such as main navigation and on this page.
- Use the visible heading as the name when there is one.
- A region that appears only once, such as the main content, does not need an extra name.

## Evidence

W3C Web Accessibility Initiative, Labeling Regions: "Provide labels to distinguish two page regions of the same type, such as “main navigation” and “sub-navigation” menus." Confirm the current page before you rely on it: [Label regions that share a type](https://www.w3.org/WAI/tutorials/page-structure/labels/).
