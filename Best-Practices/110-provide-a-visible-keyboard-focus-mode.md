# Provide a visible keyboard focus mode

A keyboard interface has a mode in which the focus indicator is visible.

## When it applies

Use this even when a pointer mode draws no extra indicator. The size and contrast of a custom indicator are a separate rule.

## The decision

- Show where keyboard focus is.
- If a mode hides the indicator, provide a mode that shows it.
- Confirm the current criterion before you rely on the browser default alone after restyling focus.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Any keyboard operable user interface has a mode of operation where the keyboard focus indicator is visible." Confirm the current page before you rely on it: [Provide a visible keyboard focus mode](https://www.w3.org/TR/WCAG22/#focus-visible).
