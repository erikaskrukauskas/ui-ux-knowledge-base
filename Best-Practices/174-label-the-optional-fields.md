# Label the optional fields

Optional fields are few, and each one says that it is optional.

## When it applies

Use this when a form includes a question some people may skip.

## The decision

- Remove optional questions you do not need.
- If one or two remain, label them optional.
- Do not make people discover the requirement by submitting.

## Evidence

Nielsen Norman Group, 1 May 2016: "If some fields truly are necessary, but only apply to a subset of users, don’t make users find out through trial and error." Confirm the current page before you rely on it: [Label the optional fields](https://www.nngroup.com/articles/web-form-design/).
