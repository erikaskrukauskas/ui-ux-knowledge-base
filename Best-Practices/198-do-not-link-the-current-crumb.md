# Do not link the current crumb

The crumb for the current view is not a link. A link that goes nowhere teaches the wrong thing.

## When it applies

Use this at the end of a breadcrumb trail.

## The decision

- Leave the current item as text.
- Make it look different from the ancestor links.
- Every earlier crumb is a place the person can open.

## Evidence

Nielsen Norman Group, last reviewed 1 September 2026: "You should never have a link that does nothing. The last breadcrumb (denoting the current page) should not be a link." Confirm the current page before you rely on it: [Do not link the current crumb](https://www.nngroup.com/articles/breadcrumbs/).
