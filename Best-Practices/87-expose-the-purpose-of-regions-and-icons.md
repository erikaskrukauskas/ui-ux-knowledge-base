# Expose the purpose of regions and icons

In markup, the purpose of components, icons, and regions can be determined programmatically. This is the stronger identification criterion.

## When it applies

Use this when that criterion is in scope.

## The decision

- Expose the purpose of a region, such as navigation or main.
- Expose the purpose of an icon, not only its picture.
- Confirm the current criterion before you treat a visible label as a substitute for the purpose.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "In content implemented using markup languages, the purpose of user interface components, icons, and regions can be programmatically determined." Confirm the current page before you rely on it: [Expose the purpose of regions and icons](https://www.w3.org/TR/WCAG22/#identify-purpose).
