# Include only real pages in the trail

Every crumb except the current one opens a page. A category with no page stays out of the trail.

## When it applies

Use this when a menu has labels that are not destinations.

## The decision

- Include only ancestors the person can open.
- Leave out a grouping that has no view of its own.
- The trail is a path, not a copy of every menu label.

## Evidence

Nielsen Norman Group, last reviewed 1 September 2026: "Each node in the breadcrumb trail should be a link to an ancestor page." Confirm the current page before you rely on it: [Include only real pages in the trail](https://www.nngroup.com/articles/breadcrumbs/).
