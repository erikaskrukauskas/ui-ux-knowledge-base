# Repeat shared instructions on every step

Instructions that apply to the whole process appear on every step.

## When it applies

Use this when a form spans more than one view.

## The decision

- Repeat the rules a person needs on that step, including formats and required markers.
- Do not assume they remember the first view.
- Keep the repeated text short.

## Evidence

W3C Web Accessibility Initiative, Multi-page Forms: "Repeat overall instructions on every page." Confirm the current page before you rely on it: [Repeat shared instructions on every step](https://www.w3.org/WAI/tutorials/forms/multi-page/).
