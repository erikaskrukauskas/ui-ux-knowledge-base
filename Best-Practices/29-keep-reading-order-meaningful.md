# Keep reading order meaningful

When order changes the meaning, the reading order matches that meaning, including when the layout is linearized.

## When it applies

Use this when columns, cards, or positioned regions would be read in the wrong order if taken one after another.

## The decision

- Set the sequence to the order a person needs for the task.
- Check the order with the layout removed, not only by looking at the visual grid.
- A visual grouping still needs this sequence. See the structure rule.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "When the sequence in which content is presented affects its meaning, a correct reading sequence can be programmatically determined." Confirm the current page before you rely on it: [Keep reading order meaningful](https://www.w3.org/TR/WCAG22/#meaningful-sequence).
