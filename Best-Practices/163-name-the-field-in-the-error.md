# Name the field in the error

An error uses the field's label so the person can find the control.

## When it applies

Use this in a summary and beside the field.

## The decision

- Repeat the label the person can see.
- Describe the problem in plain language.
- Remind them of the format when the format is the problem.

## Evidence

W3C Web Accessibility Initiative, User Notification: "Reference the label of the corresponding form control, to help the user recognize the control." Confirm the current page before you rely on it: [Name the field in the error](https://www.w3.org/WAI/tutorials/forms/notifications/).
