# Show that more items are loading

When more items load below what is on screen, the view says so. Silence looks like the end.

## When it applies

Use this when a list fetches more as the person reaches the bottom.

## The decision

- Show that more is loading.
- Do not leave a gap that looks like the end of the list.
- A load-more control is itself the sign that more exists.

## Evidence

Nielsen Norman Group, 4 September 2022: "Usually, this problem arises when there is no indication that additional content is loading as users reach the end of their preloaded content." Confirm the current page before you rely on it: [Show that more items are loading](https://www.nngroup.com/articles/infinite-scrolling-tips/).
