# Do not split a comparison across tabs

Information the person must compare stays on one view, not behind separate tabs.

## When it applies

Use this when two panels would have to be remembered to be compared.

## The decision

- Put compared facts on one page.
- Use tabs only when one panel at a time is enough.
- Switching tabs to compare raises the cost and the memory load.

## Evidence

Nielsen Norman Group, last reviewed 2 September 2026: "Otherwise, users must repeatedly switch between tabs to compare or reference information." Confirm the current page before you rely on it: [Do not split a comparison across tabs](https://www.nngroup.com/articles/tabs-used-right/).
