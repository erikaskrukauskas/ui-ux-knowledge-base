# Offer more than one way to find a view

Inside a set of views, the person has more than one way to locate a view, unless that view is a step in a process or the result of a step.

## When it applies

Use this for a body of content, not for the second step of a checkout.

## The decision

- Offer at least two of: navigation, search, a map, or a listing.
- A process step can have one path. Do not add a second path that skips a required step.
- Confirm the current exceptions before you omit a second way.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "More than one way is available to locate a web page within a set of web pages except where the web page is the result of, or a step in, a process." Confirm the current page before you rely on it: [Offer more than one way to find a view](https://www.w3.org/TR/WCAG22/#multiple-ways).
