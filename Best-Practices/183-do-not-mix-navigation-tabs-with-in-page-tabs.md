# Do not mix navigation tabs with in-page tabs

A tab set either stays on the view or it navigates. It does not do both.

## When it applies

Use this when several tabs share one list.

## The decision

- In-page tabs keep the person on the view and show related content.
- Navigation tabs move to a different view.
- If both kinds appear in the product, make them look different.

## Evidence

Nielsen Norman Group, last reviewed 2 September 2026: "Mixing in-page and navigation tabs within one tab control will disorient users." Confirm the current page before you rely on it: [Do not mix navigation tabs with in-page tabs](https://www.nngroup.com/articles/tabs-used-right/).
