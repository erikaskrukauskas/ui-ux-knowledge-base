# Name a functional image by its action

An image that is a link or a button is named for the action it starts, not for how it looks.

## When it applies

Use this when an icon, a logo, or a picture is the control.

## The decision

- Say the destination or the action: print this page, search, or home.
- Do not name the picture of the object when the person needs the action.
- If the same link already has that text, leave the image unnamed so it is not read twice.

## Evidence

W3C Web Accessibility Initiative, Functional Images: "The text alternative for the image should convey the action that will be initiated (the purpose of the image), rather than a description of the image." Confirm the current page before you rely on it: [Name a functional image by its action](https://www.w3.org/WAI/tutorials/images/functional/).
