# Put the form instructions before the fields

Instructions that apply to the whole form come before the fields, where they are read first.

## When it applies

Use this for required markers, shared formats, and where to find help.

## The decision

- State them once, before the person enters the fields.
- Repeat a format on the field that needs it.
- Do not hide the only copy of a rule inside a field.

## Evidence

W3C Web Accessibility Initiative, Form Instructions: "Provide such instructions before the form element to ensure that it is read aloud by screen readers before they switch to Forms Mode." Confirm the current page before you rely on it: [Put the form instructions before the fields](https://www.w3.org/WAI/tutorials/forms/instructions/).
