# Associate every data cell with its headers

Each value in a data table is tied to the header or headers that explain it.

## When it applies

Use this for any grid a person reads one cell at a time.

## The decision

- Mark header cells as headers and values as values.
- Name the direction when a header could be read as either a row or a column.
- For a header that spans several cells, state the range it covers.

## Evidence

W3C Web Accessibility Initiative, Tables Tutorial: "Header cells must be marked up with th, and data cells with td to make tables accessible." Confirm the current page before you rely on it: [Associate every data cell with its headers](https://www.w3.org/WAI/tutorials/tables/).
