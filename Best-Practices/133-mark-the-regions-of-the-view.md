# Mark the regions of the view

Header, navigation, main content, complementary notes, and footer are identifiable regions.

## When it applies

Use this on a view that has more than one block of content.

## The decision

- Mark each region so a person can jump to it.
- Put the task in the main region.
- Keep the same regions in the same order when the view changes size.

## Evidence

W3C Web Accessibility Initiative, Page Regions: "Mark up different regions of web pages and applications, so that they can be identified by web browsers and assistive technologies." Confirm the current page before you rely on it: [Mark the regions of the view](https://www.w3.org/WAI/tutorials/page-structure/regions/).
