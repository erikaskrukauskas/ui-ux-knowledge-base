# Name an icon that changes the destination

An icon that means a new view, a file type, or a format is named for that meaning.

## When it applies

Use this when a small picture sits in a link and changes what the person should expect.

## The decision

- Add the meaning in text: new window, PDF, or the format name.
- Do not rely on the picture alone.
- Keep that text in the link's name.

## Evidence

W3C Web Accessibility Initiative, Functional Images: "It has the text alternative “new window” to convey the meaning of the icon." Confirm the current page before you rely on it: [Name an icon that changes the destination](https://www.w3.org/WAI/tutorials/images/functional/).
