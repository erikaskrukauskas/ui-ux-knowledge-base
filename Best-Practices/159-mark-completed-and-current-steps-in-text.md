# Mark completed and current steps in text

A step indicator says which steps are done and which one is current, in text.

## When it applies

Use this when a known number of steps is shown as a sequence.

## The decision

- Mark completed and current in words, not only by color or position.
- Link a completed step when the person may review it.
- Save what they have entered on the current step before they leave it.

## Evidence

W3C Web Accessibility Initiative, Multi-page Forms: "Visually hidden text is used to indicate the current and completed steps." Confirm the current page before you rely on it: [Mark completed and current steps in text](https://www.w3.org/WAI/tutorials/forms/multi-page/).
