# Suggest a correction when you know one

When an input error is detected and a correction is known, offer that suggestion, unless offering it would defeat security or the purpose of the field.

## When it applies

Use this for a format, a range, or a value the system can recognize.

## The decision

- Tell the person how to fix the value, or offer the likely value.
- Do not suggest a correction that reveals a secret, such as which half of a login was wrong, when that would weaken security.
- If you do not know a correction, describe the error and leave the suggestion out.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "If an input error is automatically detected and suggestions for correction are known, then the suggestions are provided to the user, unless it would jeopardize the security or purpose of the content." Confirm the current page before you rely on it: [Suggest a correction when you know one](https://www.w3.org/TR/WCAG22/#error-suggestion).
