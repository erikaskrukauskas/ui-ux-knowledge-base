# Offer help for the current step

Context-sensitive help is available for the step the person is on.

## When it applies

Use this when you are meeting the stronger help criterion, and whenever a field's rule is easy to get wrong.

## The decision

- Put the help with the step, not only in a separate manual.
- Answer the decision in front of them.
- Confirm the current criterion before you treat a general FAQ as context-sensitive help.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Context-sensitive help is available." Confirm the current page before you rely on it: [Offer help for the current step](https://www.w3.org/TR/WCAG22/#help).
