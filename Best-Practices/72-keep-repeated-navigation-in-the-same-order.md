# Keep repeated navigation in the same order

Navigation that repeats across views stays in the same relative order, unless the person changed it.

## When it applies

Use this for a global menu, a local section menu, or a footer that repeats.

## The decision

- Keep the same items in the same order on each view.
- Adding the current section's links is fine when the repeated portion stays stable.
- A person-chosen order may differ. The default order does not.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "Navigational mechanisms that are repeated on multiple web pages within a set of web pages occur in the same relative order each time they are repeated, unless a change is initiated by the user." Confirm the current page before you rely on it: [Keep repeated navigation in the same order](https://www.w3.org/TR/WCAG22/#consistent-navigation).
