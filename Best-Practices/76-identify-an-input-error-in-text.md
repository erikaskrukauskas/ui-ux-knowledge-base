# Identify an input error in text

When the interface detects an input error, it identifies the item and describes the error in text.

## When it applies

Use this at the field or the submission. A red border without text is not the description.

## The decision

- Name the item that is wrong.
- Describe the error in text.
- Keep the person's entry so they can repair it. See the error-writing rule.

## Evidence

W3C Recommendation, WCAG 2.2, 12 December 2024: "If an input error is automatically detected, the item that is in error is identified and the error is described to the user in text." Confirm the current page before you rely on it: [Identify an input error in text](https://www.w3.org/TR/WCAG22/#error-identification).
