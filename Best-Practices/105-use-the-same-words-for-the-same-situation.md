# Use the same words for the same situation

The same situation uses the same words and the same action. The person should not have to decide whether two labels are the same function.

## When it applies

Use this across views in one product. Platform conventions still apply; confirm the current platform page before you invent a local name for a standard action.

## The decision

- Reuse the name of a repeated action.
- Follow the platform convention for a standard action.
- When two actions differ, their names differ.

## Evidence

Nielsen Norman Group, last reviewed 30 January 2024: "Users should not have to wonder whether different words, situations, or actions mean the same thing." Confirm the current page before you rely on it: [Use the same words for the same situation](https://www.nngroup.com/articles/ten-usability-heuristics/).
