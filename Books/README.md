# Books and references

This folder catalogs interface and experience references and the notes you write about them. It is not a shelf of book files.

## What to store

- Title, author, edition, and year.
- The interface question the source helps answer.
- Original notes in your own words.
- A short quotation only when the exact wording is required, with a citation.

## What to leave out

- PDFs and ebook files. `.gitignore` ignores `*.pdf` as a backstop.
- Verbatim chapters or reconstructed passages.
- Scanned pages and bulk exports from a reading tool.

AI references belong in the AI knowledge base. Implementation, data, and release references belong in those repos. The same note-taking rule applies there.

Add a row when you start taking notes. Create `Books/notes/<slug>.md` for the notes and link it here.

## Using a book in a decision

Search your notes, then confirm the current official page before you apply an accessibility criterion or a platform rule. A book can explain a durable method, such as how to test a flow or how to order a hierarchy, and still disagree with the criterion or the platform rule in force today.
